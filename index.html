What happens under the glass

Native Windows actions, visible state and restoration records.

SURGE samples CPU, memory, GPU, network adapters, processes, disk load, latency and its own CPU/memory overhead from the local machine. The interface is served from a local-only engine on the PC, and the packaged desktop app uses Windows administrator access only for modules that require elevation.

When activated, the selected profile can switch to an existing high-performance power plan, apply capped app priority, trim safe background working sets only under pressure, refresh DNS and apply supported TCP settings. Service pause and disk optimization are optional because they can make active desktops feel slower.

The Surge Ledger records what changed and what gets restored. Performance Guard watches the session and can roll back disruptive changes before they sacrifice Windows responsiveness for one better number.
